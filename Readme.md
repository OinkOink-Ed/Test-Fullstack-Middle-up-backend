Fullstack Test Task — Список из 1 000 000 элементов
Тестовое задание на позицию fullstack: интерфейс с двумя окнами (доступные / выбранные элементы), фильтрацией по ID, инфинити-скроллом, drag&drop-сортировкой и хранением состояния на сервере в памяти.

Стек
Node.js, TypeScript, Express 5, Helmet. Пакетный менеджер — pnpm 10. Фронтенд — на выбор (по условию задания).

Запуск
pnpm install
pnpm dev        # http://localhost:3000
Сборка и запуск: pnpm build → pnpm start.
Уменьшить объём данных для локальной разработки: TOTAL_DOCUMENTS=10000 pnpm dev.

Реализовано
1 000 000 документов (ID 1..1 000 000), генерируются в памяти при старте.

Два окна: доступные и выбранные элементы.

Фильтрация по ID через инвертированный индекс с LRU-кэшем.

Инфинити-скролл страницами по 20 с курсорной пагинацией.

Сессии в памяти с TTL и серверным хранением состояния.

API
POST /api/sessions — создать сессию.

GET /api/items — страница элементов (параметры sessionId, cursor, search, searchInSelected, limit ≤ 20).

Не реализовано
Drag&drop-сортировка в правом окне (эндпоинт reorder).

Очередь запросов с дедупликацией и батчинг (1 с / 10 с).

Фронтенд-часть.

Примечание
Данные хранятся в памяти и теряются при перезапуске — это соответствует условию задания (БД не используется).
